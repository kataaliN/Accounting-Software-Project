Help & Documentation

Review incoming employee access requests before granting system access.

  • Public Request badge — Orange badge means the request came from the public Request Access form on the login page.
  • Invited badge — Grey badge means the request was created by an admin via Employee Management.
  • Requested Role — The role the person is asking to be granted.
  • Approve — Grants Active status and moves them to Employee Management.
  • Reject — Permanently removes the request.
  • Waffle menu (⠿) — Opens the navigation sidebar.
  • Profile menu — Click your name for Logout.
  • Help button (?) — Opens this panel.
