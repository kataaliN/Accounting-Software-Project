    Help — Journal Entries

    • Debits first — Debit lines always appear before credit lines.
    • Multiple lines — Use "+ Add Debit / Credit" for compound entries.
    • Must balance — Total debits must equal total credits.
    • Source Document — Optionally attach a PDF, Word, Excel, CSV, or image file as supporting documentation.
    • Reset — Clears the form. Cannot delete after submitting.
    • Tabs — Filter by All, Pending, Approved, or Rejected.
    • Search — Search by account name, amount, or description.
    • PR link — Click a PR number to view full entry details.
    • Rejected entries — Check the Comment column for the manager's reason.
