Help & Documentation

The Administrator Dashboard is your central hub.

  • Manage Employees — View, activate, deactivate, and invite employees.
  • Manage Accounts — Create and edit the chart of financial accounts.
  • Review Requests — Approve or reject pending employee access requests, including those submitted via the public Request Access form.
  • NEW badge — An orange NEW badge on Access Requests means someone submitted a request via the public form.
  • Current Employees table — Lists all employees with name, email, DOB, and status.
  • Activate / Deactivate — Toggle access without deleting the record.
  • New Employee — Submit details; routes to Access Requests for approval.
  • Filter bar — Search by name, number, or description.
  • Click a row — Opens account details popup.
  • Edit Account — Load account into form for editing.
  • 📋 Event Log — View before/after history for any account.
  • ✉ Email User — Send a message to manager or accountant inbox.
  • Public requests — Orange badge means submitted via the public form.
  • Approve — Grants Active status and moves to Employee Management.
  • Reject — Permanently removes the request.
  • Waffle menu (⠿) — Opens the navigation sidebar.
  • Profile menu — Click your name for Logout.
  • Help button (?) — Opens this panel.
