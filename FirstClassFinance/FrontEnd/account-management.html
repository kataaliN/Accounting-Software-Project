Help & Documentation

  • Search & filters — Filter by name, number, category, normal side, or status.
  • Click a row — Opens the account details popup with an Edit and View Ledger button.
  • Edit Account — Loads account into form; row highlights green while editing.
  • Cancel Edit — Discards changes and returns to create mode.
  • 📋 Event Log — Click the log icon on any row to see the full before/after history for that account, including who made each change and when.
  • ✉ Email User — Compose and send a message to a manager or accountant via your email client.

Every account change is recorded automatically.

  • Created — First-time creation shows all fields with no "before" image.
  • Modified — Shows only the fields that changed, with before (red) and after (green) values.
  • Journal Posted — When a journal entry is approved, the balance change is recorded with the approver's name and timestamp.
  • Waffle menu (⠿) — Opens the navigation sidebar.
  • Profile menu — Click your name or avatar for Logout.
  • Help button (?) — Opens this panel.
